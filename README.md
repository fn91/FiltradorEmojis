# 😎 Súper Filtro de Emojis

Un buscador de emojis hecho con HTML, CSS y JavaScript puro. Permite filtrar emojis por nombre, categoría y copiarlos al portapapeles con un solo clic.

---

## 📦 Estructura del proyecto

emoji-superfiltro/
├── index.html # Archivo principal HTML
├── style.css # Estilos personalizados
└── script.js # Lógica y funcionalidad

---

## ✨ Características

- 🔍 **Búsqueda en tiempo real** por nombre de emoji.
- 🗂️ **Filtrado por categorías** dinámico.
- 📋 **Copiar al portapapeles** al hacer clic en un emoji.
- 🧩 Fácil de integrar en aplicaciones como chats o formularios.

---

## 🚀 Cómo usar

1. Clona este repositorio o descarga los archivos.
2. Abre `index.html` en tu navegador favorito.
3. ¡Listo! Escribe para buscar y haz clic para copiar.

---

## 🧠 Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
